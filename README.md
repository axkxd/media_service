# Media Service

**REST API микросервис для приёма, обработки и управления медиафайлами.**  
Проект реализован на Python с использованием FastAPI и предназначен для загрузки, хранения, обработки и выдачи файлов с сохранением метаданных в базе данных.

---

## Описание

Media Service — это backend-сервис, который принимает файлы через HTTP-запросы, сохраняет их на сервере и асинхронно отправляет в облачное хранилище. Для каждого загруженного файла генерируется уникальный идентификатор (UID), а метаданные (размер, формат, оригинальное имя и расширение) сохраняются в PostgreSQL для последующей работы.

---

## Что делает проект

- **Загрузка медиафайлов** через REST API (POST)  
- **Сохранение файлов на диск** и асинхронная отправка в облако  
- **Генерация уникального UID** для каждого файла  
- **Сохранение метаданных** в PostgreSQL через SQLAlchemy  
- **Получение файлов по UID** через API  
- **Периодическая очистка** старых файлов с помощью cron-задачи  
- **Базовое тестирование функциональности**

## Как запустить

### Через Docker

1. Склонируй репозиторий:
```bash
   git clone https://github.com/axrmxv/media_service.git
   cd media_service
```
2. Создай .env на основе примера:
```bash
   cp .env.example .env
```
и заполните переменные окружения для подключения к БД и облаку.
3. Запусти сервис:
```bash
docker compose up --build
```

### Локальный запуск без Docker

1. Установи зависимости:
```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```
2. Заполни `.env` переменными окружения
3. Запусти сервер:
```bash
uvicorn app.main:app --reload --host 0.0.0.0 --port 8080
```

### Примеры запросов к API
## Загрузка файла

POST /files/
```bash
curl -X POST "http://localhost:8080/files/" \
  -F "file=@/path/to/your/file.jpg"
```
Ответ:
```bash
{
  "uid": "123e4567-e89b-12d3-a456-426614174000",
  "filename": "file.jpg"
}
```

## Получение файла по UID

GET /files/{uid}
```bash
curl "http://localhost:8080/files/123e4567-e89b-12d3-a456-426614174000"
```
Ответ:
файл будет отправлен в ответе как загрузка.

### Тесты
